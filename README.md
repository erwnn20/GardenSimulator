# Simulateur de Jardin Virtuel 🌱

## Description
Ce projet est un simulateur de jardin virtuel où les joueurs peuvent planter, entretenir et faire croître diverses plantes. Ils doivent gérer les besoins des plantes en eau, lumière et nutriments, tout en faisant face à des événements aléatoires qui influencent leur santé.  

Ce projet met en pratique la programmation orientée objet (POO) en Python, la manipulation de données et l'utilisation de modules pour gérer les événements et la sauvegarde.

## Fonctionnalités
### 🏡 Fonctionnalités de base
- **Création du jardin** : Possibilité de planter différentes espèces (fleurs, légumes, arbres) avec des besoins spécifiques.
- **Gestion des plantes** :
  - Planter des graines et suivre leur croissance.
  - Arroser, fertiliser et entretenir les plantes pour favoriser leur développement.
- **Suivi de l’état des plantes** :
  - Indicateurs de santé, croissance et maturité.
  - Notifications pour rappeler les soins nécessaires.
- **Événements aléatoires** : Tempêtes, sécheresses, maladies et parasites pouvant impacter les plantes.
- **Évolution du jardin** : Croissance des plantes avec production de graines, fleurs ou fruits.

### 🔥 Fonctionnalités avancées (optionnelles)
- **Types de sol et environnement** : Influence du type de sol et des conditions climatiques sur la croissance.
- **Interactivité avancée** : Ajout de décorations, systèmes d'irrigation et mini-jeux.
- **Système économique** : Vente de plantes ou produits pour acheter des graines et outils.
- **Sauvegarde et chargement** : Possibilité d'enregistrer et reprendre une partie.

## 🛠️ Exigences techniques
- **Langage** : Python
- **Concepts** :
  - Programmation orientée objet (POO) avec des classes pour les plantes, le jardin et les événements.
  - Utilisation de modules Python pour la sauvegarde des données et la gestion des événements aléatoires.
  - Manipulation de structures de données pour suivre l’état des plantes et ressources.

## 🚀 Installation et Exécution
1. **Cloner le projet** :
   ```bash
   git clone https://github.com/erwnn20/GardenSimulator.git
   cd GardenSimulator
   ```
2. Exécuter :
   ```bash
   python main.py
   ```
